MultiUAV / 网络仿真 · 数据可视化

让无人机网络
变得直观可见

把仿真中的节点、分簇关系与网络性能放到同一张工作台。连接 ns-3 仿真、C++ 中间件与浏览器前端，在不同场景之间观察节点运动，查看路由、MAC 与分簇指标。

  • ns-3 / C++
  • Three.js
  • WebSocket
  • RabbitMQ
  • Docker
体验交互演示了解系统架构

ns-3.34 · C++
三维展示
Three.js · 节点态势
数据链路
HTTP · WebSocket
运行与存储
Docker · MariaDB
交互演示项目功能系统架构观察指标使用流程
01

走进仿真工作台

保留项目的实际前端样式，用模拟节点和指标体验场景切换、节点详情与数据看板。

模拟数据展示

所有数值均为界面演示生成，不代表真实仿真结果，也不用于比较算法性能。

MultiUAV / 浏览器演示
独立打开 ↗

桌面：拖动与缩放画板，右键节点查看基础信息和分簇信息；悬停簇头查看成员连线。

触屏：输入节点 ID，点击“查看节点”；在下方切换路由、MAC 与分簇指标。

演示支持暂停、场景保存、JSON／CSV 导出；配置预览可改变场景、算法、节点数及 MAC 协议。完整仿真参数由实际系统提交给 ns-3 执行。

02

从节点运动到网络行为

围绕“网络里发生了什么”，将空间关系、运行状态和指标历史放在一起观察。

SPATIAL VIEW

三维节点态势

显示节点位置与运动轨迹。通过颜色边框与光环区分簇头、簇成员和访客，悬停簇头展示成员关系。

MULTI-SCENE

多场景独立展示

四个场景分别维护节点和指标历史，通过 sceneId 归属数据。同一算法可在不同场景展示不同参数。

NODE INSPECTOR

节点详情与定位

根据节点 ID 定位，在基础信息与分簇信息中查看坐标、速度、能量、所属簇头、权重和 IP。

METRICS

分层指标看板

路由、MAC 与分簇指标按页签切换。MAC 时延支持优先级与平均视图，避免不同层的信息挤在同一画面。

SIMULATION SETUP

参数化仿真

配置算法、节点规模、移动模型、通信区域、业务流量和能量参数，指定数据所对应的展示场景。

DATA EXPORT

保存与导出

保存本地场景状态，导出场景 JSON、路由 CSV 与分簇 CSV，便于进一步整理和分析。

03

仿真、数据与界面的连接

由仿真端生成状态，中间件处理数据，浏览器专注交互与展示。

数据按场景归属

节点快照携带场景与算法标识。新位置通过插值过渡，完整快照与增量更新分别处理；切换场景时，加载对应节点和指标历史。

可配置的队列消费

single 每次获取一条消息；drain 持续消费，在连续两次空轮询后等待，队列达到配置阈值再恢复。前端按消息内容更新展示。

04

在不同层面观察网络

一组空间状态，配合三组指标，让运行过程更容易理解。

指标与观察对象
层面展示内容观察对象
节点位置、速度、角色、能量、簇头、权重、IP节点运动与分簇归属
路由平均时延、丢包率、收敛时间、平均吞吐量端到端通信表现
MAC时延、信道利用率、丢包率、吞吐量信道访问与 QoS 优先级
分簇簇首与成员平均生命周期、簇维护消息、簇首声明消息、Guest 维护消息分簇稳定性与维护开销
ALGORITHM & PROTOCOL

当前控制台提供 WOA、DFP-LR-WOCA、DFP-LR-WOCA-no-RK 三种分簇算法；MAC 支持 eemac 与 qosmac。不同演示场景用于展示界面能力，曲线差异由模拟函数生成。

05

一次完整的观察流程

从参数配置开始，到场景观察，再到数据整理。

  1. 01

    确定仿真与场景

    选择目标场景，设置算法、节点数、MAC、移动模型与业务参数。

  2. 02

    观察节点与分簇

    查看运动中的节点，定位目标节点，检查基础状态和所属簇头。

  3. 03

    切换指标与场景

    浏览路由、MAC、分簇曲线，切换场景时保留各自的数据上下文。

  4. 04

    导出数据进一步分析

    保存场景状态，导出 JSON 或 CSV，接入后续的数据整理工作。
